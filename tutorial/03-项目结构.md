写代码就像盖房子，得先画好图纸，知道哪里是厨房、哪里是卧室，才能动工。

## 3.5 创建Python虚拟环境

**虚拟环境**是Python的一个机制：每个项目有自己独立的Python包，互不干扰。就像每个项目有自己的"工具箱"。

```bash
# 在项目根目录执行
cd D:\code\deepseek    # Windows
# cd ~/code/deepseek    # Mac/Linux

# 创建虚拟环境
python -m venv .venv
```

这会在项目里生成一个 `.venv` 文件夹，里面是这个项目专属的Python环境。

### 激活虚拟环境：

**Windows (PowerShell)：**
```powershell
.venv\Scripts\activate
```

**Windows (CMD)：**
```cmd
.venv\Scripts\activate.bat
```

**Mac/Linux：**
```bash
source .venv/bin/activate
```

激活成功后，终端提示符前面会出现 `(.venv)` 字样。

> ⚠️ **每次新开一个终端窗口，都要重新激活虚拟环境！**

## 3.6 安装Python依赖包

确保虚拟环境已激活（终端前面有 `(.venv)`），然后：

```bash
# 使用清华镜像加速下载（国内用户）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

等待几分钟，所有依赖包安装完成。这些包是：

| 包名 | 用途 |
|------|------|
| `fastapi` | Web框架，接收HTTP请求 |
| `uvicorn` | ASGI服务器，运行FastAPI应用 |
| `langchain` | LangChain框架，构建AI应用 |
| `langgraph` | LangGraph框架，编排多智能体 |
| `langchain-openai` | 连接OpenAI兼容API（包括DeepSeek） |
| `pymysql` | Python连接MySQL的驱动 |
| `redis` | Python连接Redis的驱动 |
| `numpy` | 数学计算库（向量运算） |
| `httpx` | 发送HTTP请求 |
| `duckduckgo-search` | 免费网络搜索 |
| `python-dotenv` | 读取.env配置文件 |
| `pydantic` | 数据校验 |
| `sse-starlette` | SSE流式传输支持 |

## 3.7 验证环境是否OK

```bash
# 确保虚拟环境已激活
# 测试能否导入关键包
python -c "import fastapi; import langchain; import langgraph; print('✅ 所有核心包导入成功')"
```

如果输出 `✅ 所有核心包导入成功`，就说明环境准备好了。
