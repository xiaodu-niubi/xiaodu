# 第7课：向量数据库 —— 本地向量存储

> 🎯 **本课目标**：写一个简易的向量数据库，支持语义搜索（搜"水果"能找到"苹果"）。

---

## 7.1 什么是向量数据库？（小白友好版）

### 传统数据库搜索 vs 向量数据库搜索

| 传统搜索（MySQL LIKE） | 向量搜索 |
|------------------------|---------|
| 搜"苹果" → 只能找到含"苹果"的文档 | 搜"苹果" → 也能找到含"水果"、"红富士"的文档 |
| 精确匹配 | 语义匹配 |
| 不理解意思 | 理解意思 |

### 一个例子帮你理解：

知识库里有这段话：
> "我们公司提供云计算服务，包括虚拟主机、对象存储和CDN加速。"

用MySQL搜索"服务器租用" → **搜不到**（因为文档里没有"服务器"和"租用"这些词）。

用向量搜索"服务器租用" → **搜得到**！因为"云计算服务"和"服务器租用"在**语义上是相近的**。

### 向量是什么？

向量就是一串数字，比如 `[0.12, -0.45, 0.78, 0.33, ...]`（384个数字）。

"苹果" → 转成向量 → `[0.1, 0.3, -0.2, ...]`
"水果" → 转成向量 → `[0.15, 0.28, -0.18, ...]`
"汽车" → 转成向量 → `[-0.5, 0.7, 0.4, ...]`

"苹果"和"水果"的向量很接近（夹角小）→ 语义相近 ✅
"苹果"和"汽车"的向量差很远（夹角大）→ 语义无关 ❌

---

## 7.2 我们要做什么？

我们要做一个**简易的本地向量数据库**，接口模仿Chroma（一个流行的向量数据库）：

- `add_documents()` → 把文档块和它们的向量存起来
- `query()` → 根据提问向量，找到最相似的文档块

数据存到 `vector_data/vectors.pkl` 文件（用pickle序列化）。

## 7.3 写代码：`src/database/chroma_client.py`

```python
"""简易向量数据库 - 基于 numpy 的本地向量存储（无需外部服务）

这个实现直接替代了 Chroma 向量数据库，适合学习和小规模使用。
"""
import os
import pickle
import numpy as np

# 向量数据存储目录
VECTOR_STORE_DIR = os.path.join(os.path.dirname(__file__), '..', '..', 'vector_data')


class ChromaClient:
    """本地向量存储（接口兼容 Chroma）
    
    数据存储格式（一个字典）：
    {
        "ids": ["doc1_chunk_0", "doc1_chunk_1", ...],      # 每个文档块的ID
        "documents": ["文档块1的内容", "文档块2的内容", ...], # 文档块文本
        "metadatas": [{"filename": "a.md"}, ...],            # 元数据
        "embeddings": [[0.1, 0.2, ...], [0.3, 0.4, ...]]   # 向量
    }
    """

    def __init__(self):
        self._data = None
        # 确保存储目录存在
        os.makedirs(VECTOR_STORE_DIR, exist_ok=True)

    @property
    def data(self) -> dict:
        """懒加载：第一次访问时才从磁盘读取"""
        if self._data is None:
            self._data = self._load()
        return self._data

    def _load(self) -> dict:
        """从磁盘加载向量数据"""
        path = os.path.join(VECTOR_STORE_DIR, 'vectors.pkl')
        if os.path.exists(path):
            try:
                with open(path, 'rb') as f:
                    return pickle.load(f)
            except Exception:
                pass  # 文件损坏，返回空数据
        return {"ids": [], "documents": [], "metadatas": [], "embeddings": []}

    def _save(self):
        """保存向量数据到磁盘"""
        path = os.path.join(VECTOR_STORE_DIR, 'vectors.pkl')
        with open(path, 'wb') as f:
            pickle.dump(self._data, f)

    # ── 接口兼容 ──
    @property
    def collection(self):
        """兼容 Chroma 接口，返回自身"""
        return self

    # ═══════════════════════════════════════════
    # 核心操作
    # ═══════════════════════════════════════════

    def add_documents(
        self,
        ids: list[str],
        documents: list[str],
        metadatas: list[dict],
        embeddings: list[list[float]],
    ):
        """批量添加文档块到向量库
        
        参数：
        - ids: 每个文档块的唯一ID
        - documents: 文档块的文本内容
        - metadatas: 文档块的元数据（来源文件、领域等）
        - embeddings: 文档块对应的向量（384维的浮点数列表）
        """
        self.data["ids"].extend(ids)
        self.data["documents"].extend(documents)
        self.data["metadatas"].extend(metadatas)
        self.data["embeddings"].extend(embeddings)
        self._save()  # 持久化到磁盘

    def query(
        self,
        query_embedding: list[float],
        n_results: int = 5,
        where: dict = None,
    ) -> dict:
        """根据查询向量检索最相似的文档块
        
        核心算法：余弦相似度
        
        流程：
        1. 把查询向量和所有存储向量归一化（变成单位向量）
        2. 计算点积 = 余弦相似度
        3. 按相似度从高到低排序
        4. 返回Top-K结果
        
        返回格式（兼容Chroma）：
        {
            "ids": [["id1", "id2", ...]],
            "documents": [["文档1", "文档2", ...]],
            "metadatas": [["元数据1", "元数据2", ...]],
            "distances": [[0.1, 0.3, ...]]
        }
        """
        if not self.data["embeddings"]:
            return {"ids": [[]], "documents": [[]], "metadatas": [[]], "distances": [[]]}

        # 转换为numpy数组，方便批量计算
        query_vec = np.array(query_embedding)
        stored_vecs = np.array(self.data["embeddings"])

        # ── 计算余弦相似度 ──
        # 步骤1：L2归一化（把向量变成单位向量，长度为1）
        query_norm = query_vec / (np.linalg.norm(query_vec) + 1e-10)
        #                                    ↑ 加极小值防止除以0
        stored_norms = stored_vecs / (np.linalg.norm(stored_vecs, axis=1, keepdims=True) + 1e-10)

        # 步骤2：点积 = 余弦相似度（因为两个单位向量的点积 = cos(夹角)）
        similarities = np.dot(stored_norms, query_norm)
        #                ↑ 形状: (N, 384) @ (384,) → (N,)
        #                  每个值在[-1, 1]之间，1=完全相同，-1=完全相反

        # 步骤3：距离 = 1 - 相似度（越接近0越相似）
        distances = 1.0 - similarities

        # 步骤4：按距离升序排序，取前n_results个
        indices = np.argsort(distances)[:n_results]

        result_ids = []
        result_docs = []
        result_metas = []
        result_distances = []

        for i in indices:
            # 如果有元数据过滤条件
            if where:
                meta = self.data["metadatas"][int(i)]
                match = True
                for k, v in where.items():
                    if meta.get(k) != v:
                        match = False
                        break
                if not match:
                    continue

            result_ids.append(self.data["ids"][int(i)])
            result_docs.append(self.data["documents"][int(i)])
            result_metas.append(self.data["metadatas"][int(i)])
            result_distances.append(float(distances[int(i)]))

        return {
            "ids": [result_ids],
            "documents": [result_docs],
            "metadatas": [result_metas],
            "distances": [result_distances],
        }

    def delete_by_document_id(self, doc_prefix: str):
        """删除指定文档的所有分块"""
        to_keep = []
        for i, meta in enumerate(self.data["metadatas"]):
            if meta.get("document_id") != doc_prefix:
                to_keep.append(i)

        self.data["ids"] = [self.data["ids"][i] for i in to_keep]
        self.data["documents"] = [self.data["documents"][i] for i in to_keep]
        self.data["metadatas"] = [self.data["metadatas"][i] for i in to_keep]
        self.data["embeddings"] = [self.data["embeddings"][i] for i in to_keep]
        self._save()

    def collection_stats(self) -> dict:
        """获取向量库统计信息"""
        return {"total_chunks": len(self.data["ids"])}


# 创建全局唯一实例
chroma_client = ChromaClient()
```

## 7.4 核心算法图解：余弦相似度

```
        查询向量
           ↑
          /|
         / |
        /  | 夹角θ很小 → cos(θ)≈1 → 很相似！
存储向量→  |
        \  |
         \ |
          \|  夹角θ接近90° → cos(θ)≈0 → 不太相关
           → 存储向量
```

公式：
```
余弦相似度 = (A·B) / (|A| × |B|)

其中：A·B = A[0]*B[0] + A[1]*B[1] + ... + A[383]*B[383]  (点积)
     |A| = sqrt(A[0]² + A[1]² + ... + A[383]²)  (向量的长度)
```

## 7.5 测试向量数据库

创建 `test_vectors.py`：

```python
"""测试向量数据库"""
from src.database.chroma_client import chroma_client

# 1. 添加一些测试文档
test_ids = ["doc1_chunk_0", "doc2_chunk_0", "doc3_chunk_0"]
test_docs = [
    "苹果是一种很好吃的水果，富含维生素C",
    "奔驰汽车是德国制造的豪华汽车品牌",
    "水果包括苹果、香蕉、橙子等，多吃水果有益健康",
]
test_metas = [
    {"filename": "food.md", "domain": "food"},
    {"filename": "car.md", "domain": "car"},
    {"filename": "health.md", "domain": "health"},
]

# 造一些简单的"向量"（384维，这里造假数据）
import numpy as np
np.random.seed(42)

# 文档1和文档3语义相近（都是水果），让它们的向量相似
vec1 = np.array([0.5, 0.3, 0.8] + [0.0]*381)  # 文档1
vec2 = np.array([-0.3, 0.9, -0.2] + [0.0]*381)  # 文档2
vec3 = np.array([0.45, 0.35, 0.75] + [0.0]*381)  # 文档3（接近文档1）

test_embs = [vec1.tolist(), vec2.tolist(), vec3.tolist()]

chroma_client.add_documents(test_ids, test_docs, test_metas, test_embs)
print(f"✅ 添加了 {len(test_ids)} 个文档块")

# 2. 查询：假设用户搜"哪种水果好吃"
#    查询向量应该和文档1的向量接近
query_vec = np.array([0.48, 0.32, 0.78] + [0.0]*381).tolist()

results = chroma_client.query(query_vec, n_results=2)
print(f"\n✅ 查询'哪种水果好吃'的结果：")
for i, doc_id in enumerate(results["ids"][0]):
    doc_text = results["documents"][0][i]
    dist = results["distances"][0][i]
    print(f"   {i+1}. [{doc_id}] (距离={dist:.4f}) {doc_text[:50]}")

# 3. 查看统计
stats = chroma_client.collection_stats()
print(f"\n✅ 向量库统计: {stats}")

print("\n🎉 向量数据库测试通过！")
# 注意：距离最小的文档应该和查询最相关
```

运行：
```bash
python test_vectors.py
```

## 7.6 限制说明

这个简易向量数据库适合**学习和Demo**，但不适合生产环境（当文档量到几万级别时性能会下降）。生产环境应该用真正的向量数据库如Chroma、Milvus、Pinecone等。

但它的优点是：
- ✅ 零依赖（不需要安装Chroma服务）
- ✅ Python 3.14 也能运行
- ✅ 够我们学习用了
