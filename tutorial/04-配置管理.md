# 第4课：配置管理 —— 写 .env 和 config.py

> 本课为早期教学示例。当前工作台已改为仅从环境变量读取 LLM_API_KEY，不再加载 .env 中的模型密钥。请按根目录 README.md 配置 Windows 用户环境变量。

> 🎯 **本课目标**：学会用 `.env` 文件管理配置（密码、密钥等），让代码安全又灵活。

---

## 4.1 为什么需要配置管理？

想象一个场景：你写了一段代码连接数据库，里面写着密码 `mypassword123`。

```python
# ❌ 不好的写法：密码直接写在代码里
db = connect(host="localhost", password="mypassword123")
```

问题：
1. **不安全**：代码上传GitHub，全世界都能看到你的密码
2. **不灵活**：换了数据库密码，就得改代码、重新部署
3. **不专业**：正规项目都会把配置和代码分开

**正确的做法**：配置写在 `.env` 文件里，代码从 `.env` 读取。

```
代码 → config.py（读取.env） → .env（存放密码等配置）
```

## 4.2 第一步：创建 `.env` 文件

在项目根目录创建 `.env` 文件：

> ⚠️ `.env` 文件**没有文件名**，只有扩展名。Windows上可以在记事本里"另存为"，文件名输入 `.env`。

```bash
# 在项目根目录创建
# Windows PowerShell:
New-Item -Path ".env" -ItemType File -Force
```

然后写入以下内容：

```env
# ========================================
# DeepSeek 多智能体系统 - 配置文件
# ========================================

LLM_API_KEY=sk-xxxxxxxxxxxxxxxx
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-v4-pro

# ── MySQL 数据库配置 ──

MYSQL_PORT=3306
MYSQL_USER=deepseek
MYSQL_PASSWORD=deepseek123
MYSQL_DATABASE=deepseek

# ── Redis 缓存配置 ──
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_DB=0
REDIS_PASSWORD=deepseek-redis-2024

# ── 向量数据库配置 ──
CHROMA_HOST=localhost
CHROMA_PORT=8001

# ── 嵌入模型配置 ──
# 把文字转成向量的模型

CHUNK_SIZE=1000
CHUNK_OVERLAP=200

# ── 智能体配置 ──
MAX_AGENT_ITERATIONS=10
MEMORY_TTL_SECONDS=86400
MAX_CONTEXT_MESSAGES=20

# ── MCP协议 ──
MCP_SERVER_PORT=9000

# ── API服务 ──
API_HOST=0.0.0.0
API_PORT=8000
```

### 配置项解释：

| 配置项 | 含义 | 你需不需要改 |
|--------|------|-------------|
| `LLM_API_KEY` | DeepSeek API密钥 | ⚠️ **必须改！**填你的真实密钥 |
| `LLM_MODEL` | 使用的模型名 | 不改也行 |
| `LLM_TEMPERATURE` | 创造性参数(0~1)。越大越"脑洞"，越小越保守 | 不改也行 |
| `LLM_MAX_TOKENS` | 最大回复长度。1个token≈0.75个汉字 | 不改也行 |
| `MYSQL_HOST/PORT` | 数据库地址 | 不改 |
| `MYSQL_PASSWORD` | 数据库密码 | 和docker-compose.yml保持一致 |
| `REDIS_PASSWORD` | Redis密码 | 不改 |
| `MEMORY_TTL_SECONDS` | 对话记忆保留多久（秒）。86400=24小时 | 不改也行 |
| `MAX_CONTEXT_MESSAGES` | 最多传多少条历史消息给大模型 | 不改也行 |
| `API_PORT` | 后端服务端口。8000被占用了就改 | 根据情况改 |

> 🔑 **获取DeepSeek API密钥**：
> 1. 打开 https://platform.deepseek.com
> 2. 手机号注册
> 3. 进入"API Keys"页面
> 4. 点击"创建API Key"
> 5. 复制密钥（sk-开头），粘贴到 `.env` 的 `LLM_API_KEY=` 后面

## 4.3 第二步：写 `config.py`

这个文件负责**读取 `.env` 文件**，把里面的值变成Python变量，方便所有代码使用。

创建文件 `src/config.py`：

```python
"""配置管理 - 从环境变量加载所有配置项"""
import os
from pathlib import Path
from dotenv import load_dotenv

# 找到项目根目录的 .env 文件
env_path = Path(__file__).parent.parent / ".env"
load_dotenv(env_path)


class Settings:
    """全局配置单例
    这个类把所有配置项集中管理，其他代码通过 settings.xxx 来获取配置
    """

    # ── 大模型配置 ──
    llm_api_key: str = os.getenv("LLM_API_KEY", "")
    llm_base_url: str = os.getenv("LLM_BASE_URL", "https://api.deepseek.com/v1")
    llm_model: str = os.getenv("LLM_MODEL", "deepseek-chat")
    llm_temperature: float = float(os.getenv("LLM_TEMPERATURE", "0.7"))
    llm_max_tokens: int = int(os.getenv("LLM_MAX_TOKENS", "4096"))

    # ── MySQL 配置 ──
    mysql_host: str = os.getenv("MYSQL_HOST", "localhost")
    mysql_port: int = int(os.getenv("MYSQL_PORT", "3306"))
    mysql_user: str = os.getenv("MYSQL_USER", "root")
    mysql_password: str = os.getenv("MYSQL_PASSWORD", "")
    mysql_database: str = os.getenv("MYSQL_DATABASE", "deepseek")

    # ── Redis 配置 ──
    redis_host: str = os.getenv("REDIS_HOST", "localhost")
    redis_port: int = int(os.getenv("REDIS_PORT", "6379"))
    redis_db: int = int(os.getenv("REDIS_DB", "0"))
    redis_password: str = os.getenv("REDIS_PASSWORD", "")

    # ── Chroma 向量数据库配置 ──
    chroma_host: str = os.getenv("CHROMA_HOST", "localhost")
    chroma_port: int = int(os.getenv("CHROMA_PORT", "8001"))
    chroma_collection: str = os.getenv("CHROMA_COLLECTION", "deepseek_knowledge")

    # ── 嵌入模型配置 ──
    embedding_model: str = os.getenv("EMBEDDING_MODEL", "all-MiniLM-L6-v2")
    chunk_size: int = int(os.getenv("CHUNK_SIZE", "1000"))
    chunk_overlap: int = int(os.getenv("CHUNK_OVERLAP", "200"))

    # ── 智能体配置 ──
    max_agent_iterations: int = int(os.getenv("MAX_AGENT_ITERATIONS", "10"))
    memory_ttl_seconds: int = int(os.getenv("MEMORY_TTL_SECONDS", "86400"))
    max_context_messages: int = int(os.getenv("MAX_CONTEXT_MESSAGES", "20"))

    # ── MCP 协议配置 ──
    mcp_server_port: int = int(os.getenv("MCP_SERVER_PORT", "9000"))

    # ── API 服务配置 ──
    api_host: str = os.getenv("API_HOST", "0.0.0.0")
    api_port: int = int(os.getenv("API_PORT", "8000"))

    # ── 便捷属性(组合多个配置项) ──
    @property
    def mysql_url(self) -> str:
        """生成 MySQL 连接地址"""
        return (
            f"mysql+pymysql://{self.mysql_user}:{self.mysql_password}"
            f"@{self.mysql_host}:{self.mysql_port}/{self.mysql_database}"
            f"?charset=utf8mb4"
        )

    @property
    def chroma_url(self) -> str:
        """生成 Chroma 服务地址"""
        return f"http://{self.chroma_host}:{self.chroma_port}"


# 创建全局唯一实例，其他代码用 from src.config import settings 来获取配置
settings = Settings()
```

## 4.5 知识点总结

| 知识点 | 一句话解释 |
|--------|-----------|
| `.env` | 存放敏感配置的文件，不提交到Git |
| `python-dotenv` | 读取.env文件的库 |
| `os.getenv("KEY", "默认值")` | 从环境变量中读取值 |
| `Path(__file__).parent.parent` | 获取当前文件的爷爷目录（即项目根目录） |
| `@property` | 把方法变成属性，调用时不用括号 |

## 4.6 重要提醒

1. ⚠️ **`.env` 文件绝不能提交到GitHub！** 项目的 `.gitignore` 已配置好忽略它。
