## 17.13 你应该看到的完整调用链

当用户问"公司有哪些产品？"，系统内部发生了什么：

```
1. FastAPI 收到 POST /api/chat
2. chat_router 保存用户消息到 MySQL + Redis
3. chat_router 调用 supervisor_graph.stream_process()
4. stream_process 调用 Orchestrator.route("公司有哪些产品？")
5. Orchestrator 调用 LLM，返回 {"next_agent": "rag_agent", ...}
6. stream_process 根据路由结果，调用 _fetch_knowledge()
7. _fetch_knowledge 调用 agentic_retriever.retrieve()
8. retriever.retrieve 调用 query_analyzer.analyze() → 需要检索
9. retriever 调用 embedding_model.encode() → 生成查询向量
10. retriever 调用 chroma_client.query() → 找到相关文档块
11. retriever 调用 _deduplicate_and_rerank() → 去重排序
12. retriever 调用 _build_summary() → 构建摘要
13. stream_process 把知识库内容拼到system_prompt
14. stream_process 调用 build_llm(streaming=True)
15. LLM 流式生成回复，逐token yield 给前端
16. chat_router 保存助手回复到 MySQL + Redis
17. 完成！
```

一共17个步骤，每步都是我们写的代码！🎉

## 17.14 常见问题排查

### 问题1：启动报错 "No module named 'src.xxx'"
**原因**：文件没创建或路径不对。
**解决**：对照每节课检查文件是否都存在。

### 问题2：聊天返回错误 "LLM API key not set"
**原因**：`.env` 里没填API密钥。
**解决**：编辑 `.env`，把 `LLM_API_KEY=sk-xxxx` 改成真实密钥。

### 问题3："知识库中未找到相关信息"
**原因**：知识库没加载。
**解决**：运行 `python -m src.rag.document_loader`。

### 问题4：MySQL连接失败
**原因**：Docker容器没启动。
**解决**：`docker compose up -d`。

### 问题5：Redis连接失败
**原因**：同MySQL。
**解决**：`docker compose up -d`。
