## 1.1 这个项目是什么？

我们要做一个**多智能体（Multi-Agent）AI对话系统**。

别被名字吓到，我用大白话解释：

### 什么是"智能体（Agent）"？

**智能体就像一个"会使用工具的AI助手"。**

普通的AI（比如网页版ChatGPT）只能凭记忆回答问题。但智能体不一样：
- 它可以**调用计算器**帮你算数学题
- 它可以**搜索互联网**获取最新信息
- 它可以**查知识库**找到公司内部文档
- 它可以**执行Python代码**
- 它可以**自己决定**用什么工具、按什么顺序来解决你的问题

就像你吩咐一个能干的下属："帮我查一下公司上季度的销售额，然后算一下比去年同期增长了多少"。他会自己去翻文件、用计算器、最后给你一个结果。

### 什么是"多智能体"？

我们把不同的能力分给**不同的专家智能体**，各司其职：

```
你问一个问题
    ↓
编排智能体（经理）分析你的意图
    ↓
    ├── 知识检索智能体 → 从知识库文档中查找答案
    ├── 工具执行智能体 → 执行计算、代码、单位换算
    ├── 网络搜索智能体 → 搜索互联网获取实时信息
    ├── 记忆管理智能体 → 帮你记住对话历史
    └── 通用大模型   → 处理闲聊和代码生成
```

## 1.6 核心概念快速扫盲

### 什么是RAG（检索增强生成）？

**问题**：大模型的知识截止到训练日期，它不知道你公司的内部文档。

**解决方案**：RAG = 先把你的文档存到向量数据库 → 用户提问时先去向量数据库搜索相关段落 → 把搜到的内容连同问题一起发给大模型 → 大模型"看着资料"回答问题。

就像考试时你可以翻书，而不是凭记忆瞎猜。

### 什么是向量数据库？

普通数据库用"关键词匹配"搜索（搜"苹果"只能找到含"苹果"的文档）。

向量数据库用"语义匹配"搜索（搜"水果"能找到含"苹果""香蕉""橙子"的文档，因为它们在语义上接近）。

它把文字转成一串数字（向量），语义相近的文字，向量也相近。

### 什么是ReAct模式？

ReAct = **Re**asoning（思考）+ **Act**ing（行动）

智能体的工作循环：
```
思考：我需要查一下公司产品信息
  ↓
行动：调用 knowledge_search("产品列表")
  ↓
观察：搜索返回了3个相关文档块
  ↓
思考：信息够了，可以回答了
  ↓
最终答案：根据文档，公司提供以下产品...
```

### 什么是MCP（模型上下文协议）？

一个标准化的"工具接口协议"，让不同的工具可以像USB设备一样"即插即用"。我们项目中会简单接触。
