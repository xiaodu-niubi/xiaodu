# 第2课：环境准备 —— 安装Python、Docker，启动数据库

> 🎯 **本课目标**：在你的电脑上装好所有需要的软件，并启动MySQL和Redis数据库。

---

## 2.1 我们需要安装什么？

| 软件 | 用途 | 怎么装 |
|------|------|--------|
| **Python 3.10+** | 写后端代码 | 官网下载安装包 |
| **Docker Desktop** | 一键启动MySQL和Redis（不用手动装数据库） | 官网下载安装包 |

> 🤔 **为什么要用Docker？**
>
> 安装MySQL和Redis本来很麻烦（下载、配置、启动服务...）。Docker就像一个"应用商店"，一条命令就能把MySQL和Redis装好并启动。对于学习来说，Docker是最省事的方式。

---

## 2.2 第一步：检查你电脑上是否已安装

打开终端（Windows按 `Win+R`，输入 `cmd` 回车）：

```bash
# 检查Python
python --version

# 检查Docker
docker --version
```

如果都显示版本号，说明已安装，跳到 [2.5 启动数据库](#25-第五步启动-mysql-和-redis)。

---

## 2.3 第二步：安装Python（如果没有的话）

### Windows用户：
1. 打开浏览器，访问 https://www.python.org/downloads/
2. 点击黄色大按钮 "Download Python 3.12.x"（或更新版本）
3. 下载完成后，双击安装包
4. ⚠️ **重要**：安装界面第一页，**勾选底部的"Add Python to PATH"**（把Python加到系统路径）
5. 点击 "Install Now"
6. 安装完成后，**重启你的终端**，然后验证：
   ```bash
   python --version
   # 应该显示：Python 3.12.x
   ```

### Mac用户：
```bash
# 先安装Homebrew（如果还没有）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 用Homebrew安装Python
brew install python@3.12

# 验证
python3 --version
```

### Linux用户：
```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv -y
python3 --version
```

---

## 2.4 第三步：安装Docker Desktop

### Windows用户：
1. 访问 https://www.docker.com/products/docker-desktop/
2. 下载 Docker Desktop for Windows
3. 双击安装，一路默认选项即可
4. 安装完成后，**启动Docker Desktop应用**（在开始菜单能找到）
5. 等待右下角任务栏出现Docker图标（鲸鱼🐳），显示"Docker Desktop is running"
6. 验证：
   ```bash
   docker --version
   # 应该显示：Docker version xx.xx.x
   ```

### Mac用户：
```bash
brew install --cask docker
# 然后启动Docker Desktop应用
```

### Linux用户：
```bash
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
# 注销重新登录
```

## 2.5 第四步：启动 MySQL 和 Redis

我们项目的根目录已经有 `docker-compose.yml` 文件，它定义了MySQL和Redis。

### 理解 docker-compose.yml（小白必看）

这个文件告诉Docker："帮我启动两个服务：MySQL数据库和Redis缓存"。

```yaml
# docker-compose.yml 的核心内容（简化版解释）

services:
  mysql:                          # 服务1：MySQL数据库
    image: mysql:8.0              # 使用MySQL 8.0版本的镜像
    environment:
      MYSQL_DATABASE: deepseek    # 自动创建名为deepseek的数据库
      MYSQL_USER: deepseek        # 创建一个用户叫deepseek
      MYSQL_PASSWORD: deepseek123 # 密码是deepseek123
    ports:
      - "3306:3306"              # 把容器的3306端口映射到电脑的3306端口

  redis:                          # 服务2：Redis缓存
    image: redis:7-alpine         # 使用Redis 7版本（alpine是精简版）
    ports:
      - "6379:6379"              # 把容器的6379端口映射到电脑的6379端口
```

> 💡 **关键理解**：Docker容器就像一个"微型虚拟机"，里面运行着MySQL。通过端口映射，你的Python代码连接 `localhost:3306` 就能访问容器里的MySQL。

### 启动！

打开终端，进入项目目录，执行一条命令：

```bash
cd D:\code\deepseek    # Windows
# 或
cd ~/code/deepseek     # Mac/Linux

# 启动MySQL和Redis（-d表示后台运行）
docker compose up -d
```

首次运行会下载镜像（约500MB），需要几分钟。等待输出类似：
```
[+] Running 3/3
 ✔ Network deepseek_default    Created
 ✔ Container deepseek-mysql    Started
 ✔ Container deepseek-redis    Started
```

### 验证是否启动成功：

```bash
docker ps
```

应该看到两个容器在运行：
```
CONTAINER ID   IMAGE            STATUS                   PORTS
abc123def456   mysql:8.0        Up 2 minutes (healthy)   0.0.0.0:3306->3306/tcp
def789ghi012   redis:7-alpine   Up 2 minutes (healthy)   0.0.0.0:6379->6379/tcp
```

看到 `STATUS` 列显示 **(healthy)** 就说明成功了！✅

## 2.6 数据库会自动初始化吗？

是的！`docker-compose.yml` 里有这一行：
```yaml
volumes:
  - ./init.sql:/docker-entrypoint-initdb.d/init.sql
```

意思是：MySQL容器启动时，自动执行项目里的 `init.sql` 文件，帮我们建好3张表：

| 表名 | 存什么 |
|------|--------|
| `conversations` | 对话列表（对话ID、标题、时间） |
| `messages` | 消息记录（谁说的、说了什么、哪个对话的） |
| `knowledge_documents` | 知识库文档登记（有哪些文档、处理状态） |

你可以用数据库工具（如Navicat、DBeaver）连接看看：
- 主机：`localhost`
- 端口：`3306`
- 用户：`deepseek`
- 密码：`deepseek123`
- 数据库：`deepseek`

## 2.7 常见问题（小白必看）

### Q1: `docker` 命令找不到？
**原因**：Docker Desktop没有启动。
**解决**：启动Docker Desktop应用，等右下角鲸鱼图标显示"Running"再操作。

### Q2: 端口被占用？
**现象**：报错 `port is already allocated`。
**解决**：说明你的电脑上已经有MySQL或Redis在运行了。可以选择：
- 关掉已有的MySQL/Redis
- 或者修改 `docker-compose.yml` 中的端口号（比如把 `3306:3306` 改成 `3307:3306`）

### Q3: Docker下载镜像很慢？
**解决**：配置国内镜像加速。在Docker Desktop设置 → Docker Engine 中添加：
```json
{
  "registry-mirrors": [
    "https://docker.1ms.run",
    "https://docker.xuanyuan.me"
  ]
}
```

### Q4: Windows上Docker提示需要WSL2？
**解决**：按照提示安装WSL2即可。在PowerShell（管理员）运行：
```powershell
wsl --install
```
然后重启电脑。
